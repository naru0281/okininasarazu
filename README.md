# 株式会社お気になさらず Brand Site v2.0

「ありがとう」に対する「どういたしまして」を代行する架空企業のブランドサイトです。

## Features
- 完全レスポンシブ
- ローディング演出
- スクロール・パララックス・フェード演出
- ダークモード
- OGP / favicon / custom 404
- FAQアコーディオン
- GitHub Pages対応

> 掲載されている企業・住所・サービス・人物は架空です。
