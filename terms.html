第1条（適用）

本規約は、本サービスを利用するすべての利用者に適用されます。利用者は、本サービスへの申込みをもって本規約に同意したものとします。

第2条（利用申込み・本人確認）

  1. 利用者は、当社所定の方法により正確な情報を入力し、申込みを行うものとします。
  2. 当社は、必要に応じて本人確認書類、受取人との関係、資金の性質その他の確認を求めることがあります。
  3. 未成年者による利用については、当社が必要と判断した場合、保護者その他法定代理人の同意または確認を求めることがあります。
  4. 申込内容に虚偽、誤記または重要事項の欠落がある場合、当社は受付を拒否または保留できます。

第3条（取扱金額・手数料）

  1. 本サービスの最低取扱金額は5,000円とします。
  2. サービス手数料は、適用される部門の料率に従い、取扱金額に対して算出します。
  3. 手数料には別途消費税その他法令上必要な税額が加算されます。
  4. 振込手数料、現地対応費用その他個別に費用が発生する場合は、申込み時または実施前に案内します。

第4条（適用部門）

通常は利用者の年齢に応じて以下の部門を適用します。ただし、高額・超高額部門の条件に該当する場合は、年齢区分より優先して適用します。

少年層部門未成年 / 20％（税別）
若年層部門18～30歳 / 50％（税別）
青年層部門31～35歳 / 55％（税別）
壮年層部門36～50歳 / 60％（税別）
中年層部門51～64歳 / 45％（税別）
高齢層部門65歳以上 / 25％（税別）
高額部門100万円以上1,000万円未満 / 15％（税別）
超高額部門1,000万円以上 / 12％（税別）

※年齢区分と高額区分が重複する場合は、高額部門または超高額部門を優先します。

第5条（グレード制度）

  1. 当社は、年間の利用回数、取扱金額、支払手数料等に応じて利用者にグレードを付与することがあります。
  2. プラチナグレード利用者には、対象期間に支払われた対象手数料の10％相当を、当社所定の方法により還元します。
  3. 当社が定める一定の条件を満たすプラチナグレード利用者には、口座振込に代えて現地での現金お渡しを案内する場合があります。
  4. グレード判定基準、特典内容および適用期間は、サービス運営上の都合により変更される場合があります。

第6条（禁止事項）

利用者は、以下の行為を行ってはなりません。

  • 虚偽情報または第三者の情報を無断で使用して申し込む行為
  • 犯罪収益、違法な資金または出所を説明できない資金の取扱いを依頼する行為
  • 当社、他の利用者または第三者の権利・利益を侵害する行為
  • 当社のシステム・業務に過度な負荷または妨害を与える行為
  • 反社会的勢力への利益供与その他これに関連する行為
  • 法令、公序良俗または本規約に違反する行為
  • その他、当社が不適切と合理的に判断する行為

第7条（受付拒否・利用停止）

当社は、本人確認が完了しない場合、禁止事項に該当する疑いがある場合、システム障害、災害、金融機関の休業その他やむを得ない事由がある場合、本サービスの全部または一部を拒否、保留、中断または停止できるものとします。

第8条（キャンセル・返金）

  1. サービス処理開始前のキャンセルについては、当社所定の手続きにより受付します。
  2. 当社がすでに本人確認、入金処理、振込手続き、現地対応手配等に着手している場合、発生済みの費用・手数料を差し引く場合があります。
  3. 当社の責めに帰すべき事由によりサービス提供が完了できなかった場合は、個別に精算方法を案内します。

第9条（免責・責任の範囲）

当社は、利用者の入力誤り、金融機関の処理遅延、通信障害、天災、第三者の行為その他当社の合理的な管理を超える事由によって生じた損害について、法令上認められる範囲で責任を負わないものとします。ただし、当社の故意または重大な過失による場合を除きます。

第10条（規約の変更・準拠法・管轄）

  1. 当社は、必要に応じて本規約を変更することがあります。重要な変更はウェブサイト等で事前または速やかに周知します。
  2. 本規約は日本法を準拠法とします。
  3. 本サービスに関連して紛争が生じた場合、法令に別段の定めがある場合を除き、当社所在地を管轄する裁判所を合意管轄裁判所とします。
